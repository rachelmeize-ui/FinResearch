## Material findings

1. **P2 — Business report preview inherits financial assertions.** `static/app.js`, `reportPage()`, labels a business/industry report without AI as “财务计算报告” when coverage is complete, and always ends its subtitle with “公开披露 · 合并财务报表”; its business actual-period expression becomes “财务比较不适用年度（实际数据）”. The overview correctly states evidence-only scope, so the report should carry the same truth. Use a business/industry report status and a subtitle identifying public business/industry evidence, requested years, and the absence of verified historical webpage coverage. Preserve the user's question and evidence warnings. **Verification:** inspect a business report preview, ideally at desktop and 390 px; confirm no claim of audited/comparable financial statements is present.

2. **P2 — Single-entity contexts retain two-company remnants.** `financePage()` builds a “两家公司对比” option and maps both company slots without filtering an empty second company. `render()` and `route()` unconditionally append “与” to the breadcrumb/document title; the dangling conjunction is visible in `D-blocked.png` and `industry.png`. Use a neutral “全部研究公司” or a single-company label, filter empty company options, and join existing company names only. This is distinct from the correctly fixed main title and filtered chart legend. **Verification:** recapture a single-entity finance toolbar and inspect its options, breadcrumb and document title; no blank option or dangling conjunction should remain.

3. **P2 — Explicit business/industry selection retains an untouched financial starter question.** `newForm()` uses a financial comparison question/dimensions, and no type-change handler adjusts untouched starter values. `C-business.png` and `industry.png` consequently ask about two companies' revenue, profitability and balance sheets while displaying business/industry evidence. When the type is explicitly changed, update only untouched starter values to an appropriate question/dimensions; preserve anything the user wrote. A private-company fallback from an intentionally financial question should also preserve that question and its explicit routing explanation. **Verification:** type switching updates starter copy, while an edited question survives switching.
