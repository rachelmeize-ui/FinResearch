# 私有服务器部署

此文件描述可运行的部署配置，**不代表已经创建云服务或获得在线网址**。需要可运行 Docker 的服务器，以及终止 HTTPS 的平台网关或反向代理。保留单实例和持久化磁盘；当前 SQLite 不支持多个独立实例共享写入。

## 服务配置

Dockerfile 使用 Python 3.12，以非 root 用户运行，监听 `PORT`（默认10000）。Python 后端、前端与可移植 Excel 导出在同一个服务内，不需要本机专用 Node 包。构建：

```text
docker build -t finresearch .
```

必须通过托管平台的保密配置设置：

| 配置 | 值 |
| --- | --- |
| FINRESEARCH_PUBLIC_ORIGIN | 最终 HTTPS 网站地址，例如 https://research.example.com，不含路径 |
| FINRESEARCH_ACCESS_USER | owner，或自定账号 |
| FINRESEARCH_ACCESS_PASSWORD | 至少24位、随机生成且仅本人持有的独立密码 |
| FINRESEARCH_DATA_DIR | /var/lib/finresearch（镜像已设定） |

Render 也可从其 `RENDER_EXTERNAL_URL` 自动取得网址。密码与模型密钥是两个独立配置，不允许将模型密钥当作登录密码。浏览器首次进入会要求账号和访问密码；所有页面、研究记录、文件及导出均受保护。只有不含数据的 `/healthz` 健康检查免登录。

把持久化磁盘挂载到 `/var/lib/finresearch`，运行用户 UID=10001 必须可读写。数据库、研究文件与来源缓存都会存入此目录。`FINRESEARCH_DB` 如另行配置，也必须指向持久化目录内。磁盘不可跨多个实例并发挂载。平台需支持后台线程完成资料获取。

首次部署使用空白研究库，不自动上传本机已有研究和下载资料；本机记录保留。备份时停止写入或使用 SQLite backup API，并同时备份来源文件。迁移本机研究应另行核对资料范围及备份，不能用空白库覆盖现有库。

## 模型与来源

未配置模型也可以进行真实来源获取、财务计算和报告导出；付费模型调用额度默认0。此次部署准备不迁移本地模型密钥，不增加模型额度。真实年报网站是否允许云端 IP 访问，需要在选定平台上线后实际检验，不能用本地成功替代云端检索验收。

## 验证状态

已增加远程缺少保护时拒绝启动、未登录401、错误网站403、跨站请求403、健康检查、数据目录与Excel公式缓存检查。具体运行结果保存在本机 test-results，不包含个人研究库。容器构建及运行结果应另行记录；未启动成功不得声称线上部署完成。

## 费用与外部账号

GitHub 只保存代码。托管平台账号、服务器及持久化磁盘需另行提供；任何收费方案必须经用户明确选择。不能为了免费预览，悄悄使用重启即丢失研究记录的临时磁盘作为正式存储。
