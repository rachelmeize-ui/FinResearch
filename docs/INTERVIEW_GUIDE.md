# 当前版本面试讲解

一分钟：FinResearch面向金融专业学生和研究实习生，从真实公开年报整理财务数据，计算指标、核查出处并导出报告。它用同一任务连接四页，当前完整验证茅台与五粮液2023—2024年案例。真实模型整理一次，输出仍待人工核对。需求方向与约束由我提出，代码和自动化大量由AI协助，个人贡献以我的真实选择、操作和反馈为准。

三分钟：先讲用户纠偏——开发管理曾混进业务页面、模拟数据曾代替主案例；再演示官方披露、合并口径、四行数据、二十项出处；最后解释AI只整理已给资料、旧结论会失效，和真实测试/模拟角色的区别。

| 问题 | 对应实际答案与依据 |
|---|---|
| 为什么做？ | 把金融研究的数据、来源和交付连起来；用户真实指出旧版混杂，见PRD |
| 面向谁？ | 金融学生、研究实习生与初级数据分析者；不是开发团队管理软件 |
| 有真实访谈吗？ | 没有，三个评审角色为Synthetic，操作证据来自浏览器 |
| 数据真实吗？ | 两份公开年报实际下载，20字段保留原页、单位、hash；不是生成数字 |
| 是最新数据吗？ | 是2023—2024历史报告期，页面明确标注，未说最新行情 |
| 为什么合并净利润不同于常见数值？ | 常见摘要可能为归母；本工具采用含少数股东损益的合并净利润 |
| 毛利率怎么算？ | 收入减营业成本除收入，不是酒类分部毛利率，finance.py |
| 净利率能直接比吗？ | 采用统一计算口径但业务结构不同，茅台含财务子公司，需要解释限制 |
| 获取方式？ | 官方披露目录定位PDF→下载校验→提取报表；未接全网搜索 |
| GPT Researcher在哪里？ | 旧项目源码保留，本版本未加载，不能称此版引擎由它运行 |
| 真调模型了吗？ | deepseek-flash一次成功，4138tokens、6项引文匹配，model_runs有记录 |
| 匹配引文等于正确吗？ | 只证明文字在资料中，语义、时点和分析仍待人工检查 |
| 为什么只调用一次？ | 用户仅授权一次，预算用完后不自动重试或补充 |
| 前后端如何配合？ | 浏览器调用Python HTTP接口，SQLite保存共享任务，app.js/server.py |
| SQL用在哪？ | 保存任务、批次、问题、来源和状态，事务/参数化查询，store.py |
| Excel如何处理？ | openpyxl读取；artifact-tool写公式和出处；另用openpyxl只读核对 |
| 数据更新后呢？ | 旧AI与输入批次/来源绑定，变化后不再作为当前结论，reporting.state |
| 真问题是什么？ | 来源汇总重复参数崩溃、切页停在1500px、资料更新状态过期，都有前后证据 |
| 还有什么没做？ | 更多公司年份、行情、全网搜索、生产部署、真实外部用户试用 |
| 是AI写的吗？ | 大量工程与自动化由AI协助；不把这些说成本人手写，具体贡献按真实需求和验收记录讲 |
