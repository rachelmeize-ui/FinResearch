# 财务对比详情页图表修复 · 2026-11-22

用户截图暴露了首页看板之外的一条旧图表路径：`#finance/<研究ID>` 仍使用固定柱宽的自绘 SVG。十年双公司数据超出布局容量，柱形、数值标签和年度标签重叠。此前首页验收没有覆盖这个详情页，不能作为详情图表正常的依据。

## 修复范围

- 替换详情页旧 SVG 排版，复用本地 Apache ECharts，按容器宽度计算分组柱形。
- 取消密集的柱顶数值标签，悬停查看精确数值，点击仍进入当前研究对应公司、年度、字段的来源面板。
- 桌面显示全部年度；窄屏首次进入显示最近五年，可切换全部年度或拖动年度滑块。当前期间单独说明，图例与年份滑块分开布局。
- 保留指标、公司、图表/数据表切换。来源索引对应完整数据集，过滤单公司后仍可追溯。
- 保留 HTML 数据表作为键盘操作和图表加载失败时的替代入口；弹窗关闭事件不再抢走用户已移至其他控件的焦点。
- 原研究数据、计算公式和后端取数流程没有修改；缺失年度保留缺失值。

主要代码：`static/finance-chart.js`、`static/finance-chart.css`；接入点 `static/app.js`、`static/index.html`。`scripts/browser_engine_v3.mjs` 的旧 SVG 检查改为新图表数据检查；CI 增加新模块语法检查。

## 实际验证

执行 `./run.ps1 -Mode FinanceBrowser`，要求本地 8530 服务与已有十年、20行真实财务研究。此脚本读取已有研究，不新建任务、不重新取数、不调用模型。

2026-11-22，`scripts/browser_finance_chart.mjs` 共 9 项通过：

1. 390px 手机默认最近五年，柱形与年度文字无重叠。
2. 全十年20个值完整，柱形无交叠，不显示密集柱顶数字。
3. 真实鼠标拖动范围，能够查看早期五年。
4. 真实点击柱形，打开贵州茅台2016年营业收入的真实字段来源。
5. 净利率数值、单公司颜色、筛选后全局来源索引正确。
6. 键盘进入数据表，切换图表/数据表正常。
7. 1440px、360px及手机3倍像素渲染，柱形与年度无重叠，页面无横向溢出。
8. 明确模拟删除一条年度记录后，缺失保持 null，不补零。
9. 明确模拟图表库加载失败后，年度控件禁用，数据表仍可访问。

前7项使用本机保存的真实披露数据；最后2项是浏览器拦截响应的故障测试，不冒充外部取数验证。本轮没有重新验证外部数据源、没有屏幕阅读器完整审计、没有新增模型调用。

原始结果保存在本机 `test-results/finance-chart-fix-20261122/results.json`。截图在 `outputs/finance-chart-fix-20261122/`：`desktop-all.png`、`mobile-recent.png`、`mobile-all.png`、`mobile-earlier-range.png`、`bar-source.png`、`mobile-360-all.png`、`mobile-dpr3.png`。这些为真实浏览器截图，财务图表截图裁切至实际分析组件。测试结果与截图目录不上传 GitHub，以保留原有本机数据边界。

独立只读界面复核以用户的故障截图为主证据，重新审查上述桌面、手机与来源截图，结论为 `ship`，无待修复项。范围限于本次详情图表修复，不代表整站视觉或财务数据审计；本轮没有新的视觉稿、自动像素评分或自动设计检测结果。
