# FinResearch 产品案例 · 纠偏后的业务闭环

用户指出旧版方向混杂，尤其把模拟用户评审误解为模拟金融业务。本轮根据这一真实反馈调整定位：服务金融专业学生、证券研究实习生和初级数据分析者，用真实公开披露完成有限范围的财务研究。

P0先保证真实来源、口径、同一任务跨页共享、核验与导出；P1处理旧结论失效、页面阅读和重复；行情、全网搜索与生产部署待后续验证。没有编造访谈结论。

复用现有Python/SQLite、财务规则、引文匹配和Excel导出，在同一项目实现公开年报获取及字段出处、异步任务阶段、真实模型调用记录和统一报告状态。四页按用户任务组织，开发管理移出正式导航。源代码/数据/旧证据先备份归档。

完整案例使用茅台/五粮液2024年原披露及2023比较数，四行数据、二十金额字段。真实模型仅整理这些资料与确定性计算，输出六项待核实初稿；没有接入行情或给出投资买卖建议。

测试发现来源汇总崩溃、切页滚动位置遗留、新资料后状态不失效，分别修复并复跑；另根据截图评审收拢重复全文。三个人物为模拟评审角色，所谓操作成功由真实浏览器记录支持。57项本地检查、5个真实研究场景、7个隔离回归和16项导出检查通过，不能据此声称真实用户收益。

用户提供方向、约束和一次模型调用授权；代码、自动化与文档大量由AI完成。用户本人尚需亲自操作和反馈，不能将AI的全部实施与测试归为自己手写或亲测。
