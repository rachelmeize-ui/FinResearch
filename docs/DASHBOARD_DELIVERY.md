# 彩色研究看板与十年案例

本轮按用户提供的多图分析界面参考，改为“左侧财务报表、右侧多图、下方宽幅柱状图”的首页。创建表单保留在顶部“新建研究”入口，没有重新创建项目或替换数据库。

## 实际接入

- 财务对照表：按所选年度展示两家公司收入、合并净利润、利润率、负债率及营收同比。
- 彩色横向条形图：所选公司的逐年营业收入，颜色区分年度。
- 折线图：两家公司净利率/毛利率，可切换指标；缺失年度为null且不跨空值连线。
- 扇形/环形图：总负债与计算净资产，支持切换公司与图形；净资产为负时改用金额柱形，不绘制错误占比。
- 关键词云：当前研究问题、固定公式摘要、保存字段引文与披露标题的去重文本词频。展示前18词，其余保留在词频列表；点击可查看对应摘录。不是年报全文、行业热度或经营情绪统计，财报科目词也不代表公司实际盈亏结论。
- 宽幅分组柱状图：两家公司逐年收入和合并净利润，同为亿元，不混用金额与比例轴。

数据从已有 `/api/state` 与 `/api/tasks/<id>` 读取，没有在图表代码里写入固定财务值。图表、表格与下载共用同一研究ID；首页浏览、切换和关键词统计不会启动外部检索或模型调用。没有财务数据时显示明确空状态，不填入漂亮但虚构的图表。

## 颜色与布局

图表由本地提供的Apache ECharts 6.1.0 SVG组件绘制，原许可保留。比较公司的蓝/紫、资产构成的青绿/橙、横条的年度色、词云的词语色有各自作用范围，不将颜色当作投资优劣判断。白灰背景与原深蓝导航保留，新增配色仅作用于数据看板，没有覆盖原DESIGN.md或原研究工作区。

手机纵向重排；长年份按图表宽度抽样显示刻度但保留所有数据点，并为多行图例预留空间。词云自适应高度、明确前18词范围，不裁切文字。原生下拉、按钮、来源表格和图表的数据入口提供键盘操作路径。

## 十年真实案例

本机新增“贵州茅台 vs 五粮液｜十年财务比较”：2016—2025年，每家公司10条，共20条有效年度记录，100项字段依据。通过巨潮逐年发现和实际下载年报，再通用提取、核对单位与计算指标，没有随机数据或新增模型调用。

早期利润表使用“本期发生额/上期发生额”而不重复年份；annual_reports.py新增仅在已识别年度报告标题下允许的映射，记录column_rule。季度报告不能借此当作年度报告。新规则既有83项后端回归通过，另在实际下载的早期年报上验证。

首次流程及重试分别保留真实失败记录。最后缺失的茅台2019数据，使用已实际下载的公司官网2020年原始年报比较列补齐：
https://www.moutaichina.com/eportal/fileDir/maotaigf/resource/cms/article/408428/509375/2021033109015187282.pdf

通过同一解析器提取后只追加缺失的2019记录，没有覆盖已有较新版本的2020记录；原始文档、获取时间、SHA-256、源报告年度及比较列均已登记。完成十年覆盖不代表20个独立年度文件都自动下载成功，也不保证任何公司的任意年份都能获取。

## 验收与限制

- 83项后端检查通过，含新年度表头正反例；正式季度资料不能进入新映射。
- 15项真实浏览器检查通过：实际SVG柱形点击、键盘来源、年份/公司/指标切换、词云摘录、扇形/环形、下载、草稿与创建入口、手机、失败恢复、缺失年度和空状态。其中503、缺失记录及空状态明确使用模拟接口响应，仅验前端处理，不作为外部数据成功证据。
- 原12项创建流程检查通过，含真实创建至报告、启动失败后对同一研究重试及行业切换清除失效选择。
- 十年案例实际浏览器核对20条记录和官网比较数来源，下载Markdown及Excel；本机详细证据在test-results/decade-final-summary.json、test-results/dashboard-20261122与outputs/dashboard-20261122。
- 独立复核初判fix，指出手机年份/图例拥挤和词云裁切；修复后两项均resolved，最终ship仅覆盖该修复清单与来源单位展示确认。不宣称完成自动像素评分、真实读屏器或独立财务审计。

财报与摘录仍需人工核验。浏览器数据视图替代不了对完整披露的阅读。界面未接入实时行情、市场份额或情绪评分。GitHub发布仅包含代码和说明，不上传本地研究库、完整年报、草稿及个人报告；在线服务仍未开通。
