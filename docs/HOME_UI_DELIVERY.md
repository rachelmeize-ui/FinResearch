## 产品与视觉边界

沿用原白灰深蓝、字体和状态色；没有覆盖 DESIGN.md 或 .impeccable/design.json。首页采用批准稿的顶部导航、问题输入、公司/年度、说明栏和最近研究布局；研究页面保持原工作区导航。图像稿中的现金流提取、季度披露等未实现描述没有照搬。问题长度仍为后端支持的1000字符。

参考 GPT Researcher 的简化输入与研究过程组织、Otio的来源证据组织、Fiscal.ai的数据层次；没有复制它们的品牌或将其组件/研究引擎冒充项目新增能力。项目仍使用原生HTML/CSS/JS。生成图仅用于设计比较，实际控件和文字均由HTML实现。内置图像工具未暴露具体型号，不声称已核验为image2。

## 实际验证

通过 `run.ps1 -Mode HomeBrowser` 可运行12组浏览器检查：初始/最近研究、可选比较、键盘与类型切换、草稿恢复、输入校验、示例填写、接口失败与重试、真实创建至导出、响应式、空列表指引，以及取数启动失败后对同一研究重试、类型切换清除旧主体选择。

真实创建使用独立数据库副本和之前实际下载的公开年报缓存，取得茅台/五粮液2023—2025六份文件和六条年度财务记录；验证同一研究ID、刷新、来源抽屉、Markdown与Excel下载。没有新增金融模型调用，也没有修改用户已有研究。此项验证不是新一轮云端来源可访问性测试。

另以openpyxl读取实际下载Excel，检查六个工作表、六条公司年度记录、30条字段来源、HTTPS出处、公式与缓存结果。读取检查不会重写工作簿，不代替原生Excel重算。

接口503和空列表是明确模拟的接口状态，只用于检查前端恢复行为，不作为真实外部资料验证。最初空列表测试未强制刷新客户端状态而失败，原结果保留在本机；修正测试步骤后原10项通过；独立复核发现的两条恢复路径另补回归检查。所有测试使用0次新增付费模型调用。

截图和详细结果保存在本机 outputs/home-design-20261122 与 test-results/home-ui-20261122；生成稿、会话数据、研究库和个人报告不随代码上传。当前仍是本地运行工具，GitHub项目公开不等于已部署在线研究服务。

## 交付复核与修复

独立复核初判fix，发现两项P2：任务已创建但启动取数失败会留在原表单导致重复创建；从主体有歧义的公司研究切换到行业，旧必填候选可能阻止提交。现已改为进入已保存的同一研究并提供取数重试，切换类型也会清除失效候选。最终复核对两项修复均评分resolved，结论ship仅覆盖这两项修复清单；12项浏览器检查通过。未执行自动设计评分或真实读屏器验证，不将其写成已完成。
