# FinResearch PRD · 0.2

## 目标用户与任务
证券研究实习生、金融专业学生和初级金融数据分析人员。任务是围绕明确的公司与报告期获取公开材料，比较财务指标，检查数据依据，产出有出处、可修订的研究报告。产品不承担开发团队的Bug和需求管理。需求来自用户明确纠偏和原JD，未经外部真实访谈验证。

## 两类数据
金融数据：必须来自真实公开披露或用户导入并提供真实出处，保留报告期、原单位、币种、合并口径、页码与文件校验。失败不生成替代数字。模拟角色反馈：仅用于内部评审，必须标Synthetic；测试夹具只能进入独立测试环境。

## 核心流程
研究首页创建任务，统一保存公司、问题和维度；研究详情获取年报、展示实际进度及阻塞原因；财务分析复用该任务的最新批次，查看指标、图表与字段证据；研究详情按真实资料生成AI初稿，必要时修订核对；报告中心复用同一任务和当前结论，导出Excel/Markdown或打开可打印报告。不重复录入公司或上传同一资料。

| 优先级 | 需求 | 验收条件 |
|---|---|---|
| P0 | 真实资料获取 | 两份官方披露下载并留hash、日期和报告期；失败有记录，无模拟回退 |
| P0 | 财务与证据 | 两公司×两年共4行，20个金额字段可回原始页；元转亿元，固定比率计算 |
| P0 | 共享研究上下文 | 四个导航页使用同一task_id、来源、数据批次与状态 |
| P0 | 数据核验与交付 | 缺值/类型/重复/单位/期间检查；保存意见，实际下载带来源和公式的Excel/报告 |
| P0 | 模型真实性 | 配置、授权、执行、失败分开；只将成功真实响应标为AI初稿 |
| P1 | 数据变化后的旧结论 | 数据或来源改变后，旧AI不进入当前报告，状态变待更新 |

## 页面与数据
首页：任务与创建；详情：问题、来源、实际处理阶段、AI初稿；财务：金额、毛利率、净利率、资产负债率、营收同比、两张趋势图、字段出处与核验；报告：当前结论、限制、Excel/报告/打印。开发文档不进入四个导航。

tasks关联datasets/issues/sources/research；新增task_meta保存上下文、活动来源和归档标志，jobs保存执行状态，model_runs保存具体模型、输入批次/来源、用量与结果关联，settings保存单次授权余额。原始数据与修改日志分开，SQLite参数化SQL/事务。

## 非功能及指标
仅绑定本机，检查Host/Origin并转义前端文本；限定文件/解压/行列/正文长度；密钥只在服务端读取。外部模型无自动重试。通过固定任务完成、字段期望值、实际下载、刷新恢复和来源失效回归验收。测试通过率不等于财务真实性或用户满意度，无真实效率改善基线。

## 口径
年度、合并、CNY；净利润为合并净利润，非归母。毛利率=(营业收入-营业成本)/营业收入；净利率=合并净利润/营业收入；资产负债率=期末负债/期末资产；同比须相邻年度。茅台财务子公司及单列利息收入使跨公司净利率解释需特别谨慎。不是分部酒类毛利率、估值或买卖建议。
