# FinResearch UI 交互说明

本说明对应 `static/index.html`、`static/style.css`、`static/app.js` 的当前实现（2026-11-21）。视觉规范见根目录 DESIGN.md；本说明记录行为与边界，不代表独立上线结论。

## 页面与连续研究

| 入口 | 地址片段 | 已实现行为 |
| --- | --- | --- |
| 首页 | `#home` | 填写两家公司和问题，可展开比较维度；创建研究并启动年报获取，随后进入该研究概览。创建本身不会调用模型。最近研究最多显示四项。 |
| 我的研究 | `#studies` | 展示已保存研究，按研究名称、研究问题或期间即时筛选；打开时保留该研究身份。 |
| 报告列表 | `#reports` | 展示研究入口，进入对应研究报告。 |
| 研究概览 | `#research/<id>` | 展示公司、问题、期间、来源及 AI 状态，关键指标、研究发现和下一步。 |
| 财务对比 | `#finance/<id>` | 切换指标、公司和图表/数据表。柱形是年度离散值；金额与比例分别标单位。 |
| 来源与核验 | `#sources/<id>` | 年报、字段来源、数据问题、AI 核验，以及真实表导入和公开原文补充。旧 `#issues/<id>` 映射到此页。 |
| 研究报告 | `#reports/<id>` | 预览当前研究的计算与初稿、来源和限制，下载 Excel/Markdown，打开 HTML 打印预览。 |

研究内四页共用公司标题、研究问题、报告期、来源数与 AI 待核验数。切换研究保留当前标签；当前主导航标记为“我的研究”。浏览器哈希支持前进/后退，路由后回到页面顶部。没有研究 ID 的概览/财务/来源入口选择最近研究，无任务时进入研究列表；失效研究显示恢复入口。旧测试任务显示已归档，不混入正式研究流程。

## 动作与状态

| 动作 | 反馈与结果 |
| --- | --- |
| 获取/重新获取年报 | 按钮进入处理中；运行任务按约 500ms 轮询显示阶段。完成后刷新数据；受阻时显示错误与“检查来源或导入真实数据”入口。 |
| 查看数字或柱形 | 打开右侧来源抽屉，展示原始金额、实际 PDF 页序、口径、公式和披露链接。派生指标列出依赖字段；营收同比包含相邻上年收入。缺来源或缺输入时明确说明。 |
| 文件详情/打开 PDF | 详情抽屉展示公司、期间、获取方式/时间、SHA-256 和公开披露地址；PDF 以新页打开。 |
| 查看依据与核验 | 显示 AI 初稿、原文、审核状态和原披露入口；可修订文字、选择状态并勾选已核对确认。后端保存成功才关闭并刷新，失败保留抽屉表单且显示错误。 |
| 处理数据问题 | 选择处理状态、填写依据并保存；成功显示已保存通知。规则通过说明明确不等于人工核验。 |
| 手动导入 | 下载空模板，选 CSV/XLSX，前端检查已选文件与 2 MB 限制；后端验证数据。约束为最多 1000 行、真实 HTTPS 出处、年度/合并/CNY。成功后当前批次更新并提示。 |
| 补充公开资料 | 公司、维度、标题、网址和真实原文（最多 6000 字）；保存成功后说明旧 AI 初稿需重新检查。 |
| AI 生成入口 | 无数据、后端不允许或任务运行中禁用。可用时先显示原生确认；本次预算为 0，回归不触发新模型调用。 |
| 导出 | 依据当前研究数据、来源及审核状态；未人工核验的 AI 内容保留初稿标记。 |

操作中禁用相应按钮并显示“处理中…”，结束后恢复；失败使用顶部文字通知。抽屉保存错误额外以 `role="alert"` 在抽屉内展示并滚动至可见位置。原生表单校验覆盖必填、网址类型和长度限制。

## 空白、等待与错误

首次加载显示“正在载入研究空间”；连接失败展示恢复本地服务后重载的说明和重载按钮。没有任务时提供开始新研究入口；无匹配搜索明确提示换关键词。无可分析数据时引导获取/导入，当前指标无有效数值时提示切换指标或公司。缺失数值显示“—”，未生成 AI 时说明可以先读表、核验和导出。来源未获取、任务受阻、AI 待更新和未确认报告都有对应文字，不用虚构内容填充。

## 键盘与可访问性

- 页面提供“跳到主要内容”链接、主导航标签、当前页 `aria-current`；工作区标签是普通链接，使用 Tab/Enter 导航，不宣称 ARIA tabs 的箭头键模式。
- 按钮、链接、表单、滚动表区域和图表柱形有清晰 `focus-visible`；表格有列/行标题和可聚焦滚动区。
- SVG 柱形使用可聚焦按钮语义、描述性标签，Enter/空格可打开同一来源抽屉；表格始终提供精确值。
- 来源面板采用原生 `dialog.showModal()`、标题关联、关闭按钮及 Escape；关闭后恢复到仍存在的触发元素。切换指标/公司后恢复对应选择器焦点。
- 通知区为 `role="status"`、`aria-live="polite"`；抽屉表单错误单独使用警报角色。状态保留文字，不仅依赖颜色。
- 尊重减少动态效果偏好，关闭过渡；基础按钮没有装饰性位移动画。

实现这些语义与行为不等同于已完成所有辅助技术测试：本轮没有屏幕阅读器及真实辅助设备验证，也没有把所有浏览器原生对话框行为视为跨平台认证。

## 响应布局

桌面固定侧栏、主内容最大宽度 1440px；1100px 以下缩紧。800px 以下改顶部导航，概览侧栏移到正文后，文件操作折行；480px 以下表单和步骤单列，抽屉全宽。研究标签、表格局部横向滚动，避免整页横向溢出。

来源表最小宽度 720px、依据列最小 156px，按钮保持完整一行；手机提示向右滑动查看原始值及来源入口。财务图在窄屏重新布局，减少刻度并简化图中数字，精确值在数据表。

HTML 打印预览复用白灰深蓝、系统字体和细分隔线，独立样式为 `static/report.css`。输出仍采用基础竖线分隔文本表格；虽然设有 A4 横向打印规则，物理分页与打印表格尚未精修或验证。

## 验证与已知边界

此文档依据实现扫描，未额外运行浏览器、写入业务数据或发起模型请求。独立视觉评审见 `UI_INDEPENDENT_REVIEW.md`：首轮 P2 手机来源按钮挤压问题已通过修复后截图复审，当前限定范围结论为 SHIP。浏览器 12 项、后端 57 项、导出 16 项检查通过为协调者记录；本说明没有独立重跑这些检查，也不扩大其覆盖范围。完整交付记录见 `UI_REDESIGN_DELIVERY.md`。

未保存的创建研究、补充资料、问题处理和 AI 编辑表单没有跨导航/刷新的草稿持久化；路由或重绘可能丢失未提交内容。图表选择、切换方式和搜索状态保存在当前页面会话变量中，不承诺刷新后恢复。前端不会自动缓存离线研究数据。

本轮展示与测试使用既有真实年报和既有真实 AI 结果，不证明实时外网重取成功或本轮新模型生成成功。产品仍限本地单人、历史财报分析，未集成实时行情、GPT Researcher、估值或全网搜索；模拟角色检查不是实际用户试用。
