# 先理解并亲自完成一份真实研究

先运行run.ps1，打开研究首页，进入已有真实案例。四页共用同一个任务ID，切页不会让你再次输入公司或上传资料。

## 五个核心模块
| 模块 | 输入→处理→输出 | 代码 | 你亲自验证 |
|---|---|---|---|
| 公开资料获取 | 公司→定位固定披露目录、下载并校验PDF→真实快照和报告期 | public_data.py | 在详情打开两份PDF；分辨缓存日期与披露日期 |
| 财务提取与计算 | 合并报表→提取元、统一亿元、按固定公式计算→金额/比率/问题 | public_data.extract_pair；finance.py | 茅台2024合并净利润893.35亿元，回到64页；用收入成本手算毛利率 |
| 共享任务和保存 | 同一task_id→SQLite关联批次、来源、状态→四页一致、刷新恢复 | store.py；server.py；engine.py | 记住任务ID，跨页/刷新后看公司、期次和数据仍一致 |
| 真实模型与引文 | 真实正文+计算结果+问题→一次模型整理、连续引文校验→待核实初稿 | engine.model_job/validate_model_output | 打开六项证据；匹配文字不代表结论一定对，不要自动标人工确认 |
| 报告与失效保护 | 当前批次与来源→筛选有效初稿、写公式和出处→Excel/报告 | reporting.py；scripts/export.mjs | 下载并用自己的Excel打开；查原始单位、页码、公式和数据性质 |

命令：run.ps1 -Mode Test、-Mode Browser、-Mode CheckExport。Browser是独立副本，不再次付费。当前一次模型授权已使用，配置存在不代表允许无限调用。

产品当前不使用GPT Researcher，不做全网搜索或行情估值。你可以解释受限年报获取，不能说自动搜全网或自主Agent已经实测。

亲自练习后记录：我提出的要求____；核对的金额与页码____；发现的问题____；反馈修改____；复查结果____。这些记录支撑个人贡献，不把助手自动生成的代码、模拟反馈和测试直接归为自己的手工工作。
