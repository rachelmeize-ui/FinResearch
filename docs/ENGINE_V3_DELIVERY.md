# FinResearch 通用研究引擎交付

本轮修改了真实研究链路，正式入口为 `research_pipeline.run`。它接受公司、年度、研究问题与研究类型，调用公开来源适配器，保存真实文件、数据和失败记录。未重置数据库，未调用付费大模型。

## 现在真实支持什么

| 能力 | 已实现与实测范围 | 未承诺范围 |
|---|---|---|
| 企业识别 | 巨潮公开搜索返回的A股/港股候选、代码、交易所；网易SEC主体；米哈游非上市身份注册。歧义必须选择 | 未覆盖全球企业工商登记，不把未知企业视为上市公司 |
| A股检索 | 按输入公司代码与各个年度查询巨潮公告，筛选完整中文年报，排除摘要、英文版和更正公告等非全文 | 不是所有银行、保险、特殊格式、扫描件都能解析 |
| 通用报表解析 | 合并报表、合并/公司并列表、期末/期初列、元/千元/万元/亿元、括号费用减项、五项字段及四项比率 | OCR、任意表格结构、其他币种未完成 |
| 网易财务 | SEC submissions发现2023/2024/2025实际20-F；取得原文及companyfacts，以同一accession、CNY、年度起止匹配字段 | 尚无所有美股CIK/ticker的通用主体入口；不自动混算USD便利折算列 |
| 业务竞品 | 米哈游/网易自动转业务研究；按问题查询公开来源、读取官方网页、按维度保存可追溯原文与缺口 | 非AI长篇推演、完整历史网页快照、第三方金额估算未自动生成 |
| 行业研究 | 独立研究类型、主题识别、问题定向检索、权威域名筛选、行业维度与缺口报告 | 本轮未找到足够权威资料，不能宣称完成完整行业分析 |

自动检索没有“只允许2023/2024”的年度清单，按用户选择逐年查询。实际验证成功：茅台与五粮液2023—2025；美的集团2024—2025；网易2023—2025。更早年度和其他公司取决于来源是否存在、接口可达和报表格式，未逐一认证。

米哈游的非上市状态来自用户明确给定的任务事实，官网用于公开业务资料核验；平台没有声称连接了工商登记库。具体集团/品牌与运营子公司仍应由用户核对。

## 八个模块与分工

1. `entities.py`：真实公开主体搜索与歧义选择。公司正式名称继续从下载年报核对。
2. `annual_reports.py`、`sec_reports.py`：输入年份驱动公告/20-F发现；下载成功与解析成功分别记录。
3. `source_io.py`：公开HTTPS访问、25 MB限制、总下载时限、SHA-256、不可变内容文件及缓存索引。
4. `annual_reports.extract_cn` / SEC tag选择：读取实际文件与官方事实数据，核对单位、报表列、期间、币种和申报号。
5. `finance.py`：保留原确定性计算；`research_pipeline.consolidate`保存重复比较数的历史版本与差异。新版本数值优先，但差异只标为需核对，不擅自断定原因。
6. `business_research.py`：问题定向公开检索、短原文证据整理。公司财务数字与市场份额估算不自动写成业务事实。
7. `engine.model_job`：独立、受原有额度控制的AI解释阶段。数字由程序算；本轮调用数为0。原人工核验流程保留。
8. `reporting.py` / `exporter.py`：财务报告与业务报告分别组织，同一记录生成Markdown、HTML及Excel。

审查了旧项目 `upstream/gpt-researcher-main/gpt_researcher/skills/researcher.py`：其查询规划、检索及文档加载组织有参考价值，但依赖模型规划与额外搜索/文档运行环境，不能代替申报字段、币种和版本的确定性核验。本轮未加载GPT Researcher。实际引擎是自有公开披露适配器与证据流水线，文档不得写成已集成GPT Researcher。

| 测试 | 真实执行结果 |
|---|---|
| A：茅台 vs 五粮液，2023—2025 | 六次年度查找、六份真实PDF、六条有效公司年度记录；30项字段来源、年度图表、比率、版本对照及实际报告下载 |
| B：网易，2023—2025 | 识别NetEase, Inc.；三个20-F原文与SEC XBRL；三条CNY合并年度记录，保留tag/accession/filed，不采用USD列 |
| C：米哈游 vs 网易 | 自动切换业务研究，三个公开网页来源；产品/商业模式/市场证据或资料不足；米哈游财务数据行数0 |
| D：未知企业与失败 | 保留企业识别失败及重试记录；错误主体PDF被拒绝；正确主体PDF实际上传、解析并保存到新批次 |

| 扩展：美的集团 | 实际出现A股/港股两个候选，选择000333后用同一解析器处理2024/2025中文年报；没有固定财务值回退 |
| 行业 | 实际执行主题检索；未得到足够权威正文时显示资料不足，无财务行或虚构市场规模 |

## 外部限制与失败处理

首次探测网易IR年报页和若干文件返回403，SEC原文下载也曾出现缓慢分块响应。当前已取得三个真实20-F原文及结构化事实；抓取增加总下载时限，受限时记录失败，允许官方XBRL替代或用户上传。没有绕过登录、付费墙或验证码。

公开检索可能限流、返回不相关结果或没有权威正文。业务网页中的现行内容不等同于2023—2025历史证据；平台明确标示该限制。港股其他发行人解析、更多美股主体、非上市主体目录、行业专业数据、OCR、任意币种与跨准则比较、深度AI解释均仍有工作量。

## 数据保留与使用

原数据库已先备份，新增 `research_documents` 和 `research_attempts` 两表。旧任务、财务批次、来源、研究和模型记录没有删除或重置；原案例读取器只用于兼容与历史回归，正式取数不再调用固定案例目录。

进入首页 → 选择研究类型、公司/主题、年份、问题 → 如有歧义先选主体 → 开始研究 → 查看逐年查找/文件状态 → 核对财务或公开业务证据 → 报告下载。已有受阻任务可点击重新查找，保留原记录并新增尝试。
