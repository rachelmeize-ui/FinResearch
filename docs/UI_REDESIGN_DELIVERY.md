## 页面与真实操作路径

主导航：**首页 / 我的研究 / 报告**。工作区标签：**研究概览 / 财务对比 / 来源与核验 / 研究报告**。URL保留研究ID，刷新恢复同一研究，已保存数据来自SQLite。旧的 `#research/<id>`、`#finance/<id>`、`#reports/<id>` 链接继续有效；`#issues/<id>` 进入来源核验。

实际跑通的新用户路径：

1. 首页保留贵州茅台、五粮液或输入研究问题，点击“开始研究”。
2. 系统创建研究并提取已获取的真实2024年报快照，载入2023/2024比较数据。本轮验证复用真实快照，不声称重新联网下载成功。
3. 概览先看关键指标；进入“财务对比”，选择收入、利润、资产负债率等指标；可筛选单家公司或切换数据表。
4. 点击数字或柱形，在右侧查看原始金额、页码、口径和计算公式，必要时打开原PDF。同比会列出当年与相邻上年来源。
5. “来源与核验”查看公开年报与20项字段依据。已有AI初稿可逐项查看引文、修订并保存核验状态。没有AI初稿也能完成财务分析与导出；本轮没有新AI调用。
6. “研究报告”预览范围、计算摘要、AI初稿及真实来源，点击“下载 Excel”或“下载研究报告”；打印预览在独立页面打开。

操作、键盘与错误状态详见 `UI_INTERACTIONS.md`；字体、颜色、间距与组件规范见根目录 `DESIGN.md`。

## 模拟角色评审与可复现修复

以下是启发式模拟角色，**不是实际用户访谈**；操作成功只依据浏览器结果。

| 角色 | 发现 / 判断 | 对应修复与证据 |
|---|---|---|
| 初次使用者 | 原首页缺少直接输入与明确开始动作；创建时早返回响应可能覆盖新状态 | 首页输入常显；资料任务提交后再进入工作区，避免创建/刷新竞态；真实创建与不支持公司阻塞均通过 |
| 证券研究实习生 | 手机来源表把按钮挤成逐字换行，来源入口难辨认 | 独立来源表最小宽度720px、按钮不换行、横向滑动提示；修复前 mobile-source-action-before-fix.png，修复后 final/390-sources-right.png |
| 金融数据分析人员 | 手机直接缩放桌面SVG，刻度和数值过小；概览表可能撑宽页面 | 手机独立360单位绘图坐标、明确舍入说明、精确值保留表格/抽屉；网格子项 min-width:0，整页无溢出 |

独立视觉评审记录在 `UI_INDEPENDENT_REVIEW.md`，保留首轮问题与复核结论。设计辅助检测器未安装，未把它标成通过；由实际截图、代码检查与浏览器测试补充核验。

## 修改文件

- `static/index.html`：三项主导航、面包屑、主内容区、原生来源抽屉。
- `static/app.js`：工作区与列表、交互图表、字段来源、核验表单、报告预览、加载/错误处理及创建状态顺序。
- `static/style.css`：统一视觉tokens、响应式布局、表格、状态、焦点与来源面板。
- `static/report.css`：打印预览的字体与中性深蓝配色。
- `scripts/ui_audit.mjs`、`scripts/ui_acceptance.mjs`：真实页面审计与新版浏览器验收。
- `scripts/final_preview.mjs`：正式本地站点只读复核。
- `scripts/verify_real_export.py`：允许传入新版实际下载文件，保留原检查逻辑。
- `run.ps1`：Browser入口切换为新版验收；README及设计/交互文档同步更新。

原前端与设计文件保存在 `archive/ui-before-20261121-*`。未改动金融计算、年报解析、API密钥、SQLite核心业务或模型调用预算。

## 仍有的体验边界

- 未保存的表单草稿尚不跨标签保存，关闭或离开前需要先保存。
- 手机长表仍需横向滚动；这是保留完整金融列信息的取舍，已提供提示。
- 打印版保持基础文本表结构，复杂长表的分页未专门优化；未执行原生Excel重算。
- 本轮仅在桌面Chrome与手机宽度模拟视口验证，未做真机、屏幕阅读器或真人可用性访谈。
- 自动年报获取仍仅支持茅台/五粮液2023—2024历史数据；AI新调用仍需另行额度授权。
- 当前交付为本地可运行网站，本轮没有执行GitHub发布或云端部署。
